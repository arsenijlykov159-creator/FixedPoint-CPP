# FixedPoint-CPP 🚀

Высокопроизводительная, легковесная и настраиваемая на этапе компиляции библиотека арифметики с **фиксированной запятой** на языке **C++23**.

Эта библиотека создана как альтернатива стандартным типам с плавающей точкой (`float`, `double`). Она полностью решает проблему потери точности и ошибок округления двоичной системы (таких как `0.1 + 0.2 != 0.3`), сохраняя данные внутри класса в виде нормализованных целых чисел. Отлично подходит для систем, критичных к производительности, встроенных систем (embedded) или финансовых вычислений, где требуется абсолютная точность десятичных знаков.

---

## 🌟 Ключевые особенности

* **Метапрограммирование на C++23:** Библиотека автоматически подбирает и оптимизирует размеры встроенных типов данных (`std::int8_t`, `std::int16_t`, `std::int32_t`) с помощью `std::conditional_t` прямо во время компиляции, основываясь на выбранной вами точности.
* **Нулевые затраты в рантайме (Zero Runtime Overhead):** Десятичный множитель вычисляется на этапе компиляции с помощью быстрого `constexpr`/`consteval` алгоритма возведения в степень.
* **Защита от переполнения:** Вся логика нормализации знаков и чисел внутри конструкторов защищена строгими диагностическими проверками `assert` для отлова переполнений типов на этапе разработки.
* **Каноническая перегрузка операторов:** Реализован полный комплект арифметики и составного присваивания (`+=`, `-=`, `*=`, `/=`, `+`, `-`, `*`, `/`), обеспечивающий поведение класса, идентичное встроенным числовым типам.
* **Корректный ввод-вывод (I/O):** Полная интеграция с `std::ostream` и `std::istream`, включающая автоматическое заполнение нулями (`std::setw`) и точное сохранение знака для пограничных случаев вроде отрицательного нуля (`-0.00`).

## 🛠️ Матрица оптимизации типов и памяти

Благодаря шаблонной магии компилятор гарантирует, что ваши объекты будут занимать минимально возможное количество байт в памяти:

| Точность (знаков, `N`) | Тип дробной части | Тип целой части | Значение множителя | Макс. целое число |
| :---: | :---: | :---: | :---: | :---: |
| `N <= 2` | `std::int8_t` (1 байт) | `std::int16_t` (2 байта) | `100` | `32767` |
| `3 <= N <= 4` | `std::int16_t` (2 байта) | `std::int16_t` (2 байта) | `10000` | `32767` |
| `5 <= N <= 6` | `std::int32_t` (4 байта) | `std::int32_t` (4 байта) | `1000000` | `2147483647` |

## 💻 Примеры использования

### 1. Базовые операции и решение проблем с точностью
```cpp
#include <iostream>
#include "FixedPoint.hpp"

int main() {
    // Обычный double выдаст: 0.1 + 0.2 = 0.30000000000000004
    // FixedPoint<2>: Гарантирует абсолютную точность!
    FixedPoint<2> a{ 0.1 };
    FixedPoint<2> b{ 0.2 };
    
    FixedPoint<2> c = a + b;
    std::cout << "Точный результат: " << c << "\n"; // Выведет: 0.30
}
```

### 2. Оптимизация памяти на этапе компиляции
```cpp
// 2 знака после запятой: экстремально компактный размер
FixedPoint<2> ultra_lightweight{ 10.50 }; 
std::cout << sizeof(ultra_lightweight) << " байт\n"; // Обычно 4 байта с учетом выравнивания памяти

// 6 знаков после запятой: типы автоматически расширяются под большую вместимость
FixedPoint<6> high_precision{ 123.456789 }; 
std::cout << sizeof(high_precision) << " байт\n"; // Расширится до 8 байт
```

## 🧑‍💻 Техническая справка и архитектура

Стандартные типы данных `float` и `double` следуют спецификации **IEEE 754**, кодируя дроби через степени двойки. Это вызывает неизбежные погрешности при попытке сохранить простые десятичные значения вроде `0.01` или `0.58`. 

Данная библиотека работает нативно с десятичным основанием. Благодаря идиоматическому сведению бинарных операций (`-=`, `+`, `-`) к мастер-оператору `operator+=`, архитектура класса гарантирует строгое соблюдение инвариантов и защищает программу от незаметного искажения данных.
